TASK: P40-T8 — Stripe Payment Integration (Supabase Edition)

═══════════════════════════════════════════════════════════════
BACKGROUND & CONTEXT
═══════════════════════════════════════════════════════════════

The Cloud Edition uses a usage-based billing model. Users pay a $2 service fee per interview session + the API pass-through cost. They will purchase "credits" (sessions) via Stripe Checkout.

We are using Supabase Postgres as our database. The `profiles` table has a `payg_sessions` column.

═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════

1. CHECKOUT ENDPOINT:
   - Add a `/api/checkout` endpoint to the Cloudflare Worker.
   - It uses the Stripe Node API to generate a Stripe Checkout Session URL for purchasing "Interview Credits" (e.g., a $2.00 session pass).

2. STRIPE WEBHOOK:
   - Add a `/api/webhook/stripe` endpoint to listen for `checkout.session.completed` events.
   - On success, find the user in the Supabase `profiles` table (via customer email or a passed client_reference_id) and increment their `payg_sessions` balance by the purchased amount using the Supabase REST API (or `@supabase/supabase-js`).

3. FRONTEND INTEGRATION:
   - Add a "Top Up Balance" or "Buy Credits" button in `Settings.svelte`.
   - On click, hit `/api/checkout` and redirect the user's browser to the returned Stripe URL.
