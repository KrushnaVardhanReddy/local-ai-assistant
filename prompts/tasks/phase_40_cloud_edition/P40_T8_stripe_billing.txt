TASK: P40-T8 — Stripe Payment Integration

═══════════════════════════════════════════════════════════════
BACKGROUND & CONTEXT
═══════════════════════════════════════════════════════════════

To monetize the Cloud Edition, we are using a usage-based billing model (LLM API Cost Pass-through + $2 Service Fee per Interview). We need to integrate Stripe Checkout so users can purchase prepaid credits or start a session.

═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════

1. CHECKOUT ENDPOINT:
   - Add a `/api/checkout` endpoint to the Cloudflare Worker.
   - It uses the Stripe Node API to generate a Stripe Checkout Session URL for purchasing "Interview Credits" (e.g., $3.00 for 1 interview).

2. STRIPE WEBHOOK:
   - Add a `/api/webhook/stripe` endpoint to listen for `checkout.session.completed` events.
   - On success, provision a new API Key for the user and save it to Cloudflare KV alongside their credit balance.

3. FRONTEND INTEGRATION:
   - Add a "Top Up Balance" or "Buy Credits" button in `Settings.svelte`.
   - On click, hit `/api/checkout` and redirect the user's browser to the returned Stripe URL.
   - Upon successful return, fetch and store their new API key in `localStorage`.

═══════════════════════════════════════════════════════════════
VERIFICATION
═══════════════════════════════════════════════════════════════

1. Run the Worker locally and hit `/api/checkout` to confirm it returns a valid Stripe test-mode URL.
2. (Mock) sending a webhook event and confirm KV is updated with credits.
