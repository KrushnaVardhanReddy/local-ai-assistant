2. When clicked, show a small dropdown menu with the three options.
3. Implement the logic for the options:
   - "Copy to Clipboard": Use `navigator.clipboard.writeText(reportMarkdown)`. Show a temporary "Copied!" toast/indicator.
   - "Download as Markdown": Create a Blob with `reportMarkdown`, generate a temporary `<a>` tag, and trigger a download of `session-report.md`.
   - "Draft as Email": Open the user's default email client using `mailto:?subject=Session Report&body=` (URI encode the markdown content).
