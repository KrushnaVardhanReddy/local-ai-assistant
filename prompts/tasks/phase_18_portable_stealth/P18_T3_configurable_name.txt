OBJECTIVE

The default process name is "AudioService" (set in Cargo.toml [[bin]]). But
advanced users may want to rename it to something even more neutral for their
specific environment. Since we can't rename an EXE at runtime (Windows locks it),
we instead allow the user to rename the EXE themselves AND set the window title
and app title shown in the UI via a local settings.json file.

This gives users a simple way to personalize stealth identity without rebuilding.

1. Add a function to read optional settings.json from the same directory as the EXE:

```rust
fn read_local_settings() -> serde_json::Value {
    use std::fs;
    // Look for settings.json next to the executable
    if let Ok(exe_path) = std::env::current_exe() {
        if let Some(dir) = exe_path.parent() {
            let settings_path = dir.join("settings.json");
            if settings_path.exists() {
                if let Ok(content) = fs::read_to_string(&settings_path) {
                    if let Ok(json) = serde_json::from_str::<serde_json::Value>(&content) {
                        return json;
                    }
                }
            }
        }
    }
    serde_json::Value::Object(serde_json::Map::new())
}
```

2. In the `setup` closure of the `Builder::default()` call in lib.rs, read the
   settings and apply the window title if APP_DISPLAY_NAME is set:

```rust
let settings = read_local_settings();
let app_name = settings
    .get("APP_DISPLAY_NAME")
    .and_then(|v| v.as_str())
    .unwrap_or("AudioService")
    .to_string();

// Apply to the main window
if let Some(window) = app.get_webview_window("main") {
    let _ = window.set_title(&app_name);
}
```

3. Expose a Tauri command so the frontend can read the configured app name:

```rust
#[tauri::command]
fn get_app_display_name() -> String {
    let settings = read_local_settings();
    settings
        .get("APP_DISPLAY_NAME")
        .and_then(|v| v.as_str())
        .unwrap_or("AudioService")
        .to_string()
}
```

Register it in the invoke_handler:
```rust
.invoke_handler(tauri::generate_handler![
    // ... existing commands ...
    get_app_display_name,
])
```
