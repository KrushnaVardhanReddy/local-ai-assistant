TASK: P11-T1 — Interview Context Onboarding (Resume + Topics)

═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════
Add a self-contained "Interview Context" section to the existing Settings panel
(`frontend/src/lib/Settings.svelte`). This allows the user to paste their resume
summary, list target interview topics, and optionally specify the company/role.
This context is stored in localStorage and appended to the active System Prompt
before every LLM request, giving the AI a personalized understanding of the user
rather than answering generically.

═══════════════════════════════════════════════════════════════
BACKGROUND & MOTIVATION
═══════════════════════════════════════════════════════════════
Currently, the app sends only the raw transcript to the LLM with a generic persona
prompt (e.g., "Stealth Interview (Concise)"). Tools like Parakeet AI improve on
this by prompting the user for context before the interview starts:
  - What is your background/resume?
  - What topics will the interview cover?
  - What company and role are you applying for?

This context is silently prepended to every LLM system prompt so that answers are
tailored to the candidate's exact experience level and stack, rather than giving
a textbook explanation any stranger would receive.

═══════════════════════════════════════════════════════════════
PROMPT ASSEMBLY LOGIC
═══════════════════════════════════════════════════════════════
Modify the `handleSaveSettings` function to assemble the final system prompt
by combining the selected persona + the user's context before POSTing to the backend.

Use this assembly template (build the suffix only if the fields are non-empty):

```
function buildSystemPrompt(basePrompt, resumeContext, targetTopics, companyRole) {
  let suffix = "";
  if (resumeContext.trim()) {
    suffix += `\n\nAbout the candidate: ${resumeContext.trim()}`;
  }
  if (targetTopics.trim()) {
    suffix += `\n\nInterview focus topics: ${targetTopics.trim()}`;
  }
  if (companyRole.trim()) {
    suffix += `\n\nTarget company and role: ${companyRole.trim()}`;
  }
  return basePrompt + suffix;
}
```

POST the assembled prompt (not just `selectedPrompt`) to `/api/system_prompt`.
