TASK: P24-T1 — Lifetime BYOK (Bring Your Own Key)

═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════
Implement a "Bring Your Own Key" (BYOK) system strictly for users on the 'lifetime' billing plan. This enables power users to pay a one-time software fee and use their own Gemini API key for zero ongoing costs on our side. 

For maximum privacy, the custom API key must NEVER be stored in the backend database. It must be saved locally in the browser (`localStorage`) and transmitted securely via the WebSocket connection headers/payload during authentication.

═══════════════════════════════════════════════════════════════
CHANGES: frontend/src/lib/Settings.svelte
═══════════════════════════════════════════════════════════════

1. Add a new state variable to read/write `custom_gemini_key` from `localStorage`:
```svelte
let customGeminiKey = $state(localStorage.getItem("custom_gemini_key") || "");
```

2. Add a new input group in the Settings panel for the Custom API Key.
   This should ONLY be enabled if the user's plan is 'lifetime'. If they are not on the lifetime plan, disable it and add a small note explaining it requires a Lifetime subscription.

```html
<div class="input-group">
  <label for="customGeminiKey">Custom Gemini API Key (Lifetime Tier Only)</label>
  <input 
    type="password" 
    id="customGeminiKey" 
    bind:value={customGeminiKey} 
    placeholder="AIzaSy..." 
    disabled={authState.plan !== 'lifetime'}
  />
  {#if authState.plan !== 'lifetime'}
    <span class="text-xs text-red-400 mt-1">Requires Lifetime Subscription.</span>

  <span class="text-xs text-gray-500 mt-1">Key is stored locally and never saved to our database.</span>
</div>
```

3. Update the `handleSaveSettings` function to save the key to `localStorage`.

