TASK: P4-T1 — Scaffold Svelte 5 + Tauri 2.0 Frontend

═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════
Scaffold the Svelte 5 + Tauri 2.0 desktop app in the `frontend/` directory with
correct window configuration for a transparent, always-on-top, dock-hidden floating
overlay. The scaffold must be immediately runnable with `npm run tauri dev`.

═══════════════════════════════════════════════════════════════
CONSTRAINTS & RULES
═══════════════════════════════════════════════════════════════
- Use Svelte 5 (NOT Svelte 4) — runes-based reactivity only, no legacy `writable()` stores.
- Use Tauri 2.0 (NOT v1) — config schema and plugin system changed significantly.
- TypeScript must be enabled.
- Do NOT install any UI component library (no shadcn, no Tailwind, no DaisyUI) — vanilla CSS only.
- The scaffold's App.svelte should render only a placeholder `<h1>` — real components come in P4-T3/T4.
- `npm install && npm run tauri dev` must work with no additional setup steps.

═══════════════════════════════════════════════════════════════
CONTEXT — EXISTING REPO LAYOUT & ARCHITECTURE
═══════════════════════════════════════════════════════════════
- `frontend/` does not yet exist — create it from scratch.
- The desktop window must be: transparent background, no decorations (frameless), always on top, skipped from taskbar.
- Rust is required on the developer's machine for Tauri (Tauri 2.0 uses Rust for the shell).
- The WebSocket URL (`ws://127.0.0.1:8765/ws`) will be passed via a Vite env var `VITE_WS_URL` so it can be changed for hosted SaaS mode later.
- Window size: 420×600 default, resizable. Position: top-right corner of the screen (Tauri can set this via logical position).

═══════════════════════════════════════════════════════════════
IMPLEMENTATION HINTS
═══════════════════════════════════════════════════════════════
- Tauri 2.0 uses a flat `tauri.conf.json` structure. The Tauri 1.x nested `tauri > windows` key no longer works — windows are now under `app > windows`.
- For transparent windows on Linux, the compositor must support transparency (most modern ones do). Add `"backgroundColor": "#00000000"` explicitly in the window config as a belt-and-suspenders measure.
- To create the scaffold quickly: run `npm create tauri-app@latest . -- --template svelte-ts --manager npm` in the `frontend/` directory, then modify the generated tauri.conf.json to add the window settings above. Do NOT run it interactively — use the non-interactive flags shown.
