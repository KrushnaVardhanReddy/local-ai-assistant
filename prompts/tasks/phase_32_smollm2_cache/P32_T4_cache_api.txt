═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════
Expose two new REST API endpoints so the frontend (and power users) can
inspect and manage the local Q&A cache without restarting the backend:

  GET  /api/cache/stats   → return total cached pairs + estimated tokens saved
  DELETE /api/cache        → wipe all cache entries, return count deleted

Both endpoints require no authentication (cache is local-only and user-owned).

═══════════════════════════════════════════════════════════════
CHANGES: backend/app.py
═══════════════════════════════════════════════════════════════

1. Import qa_cache at the top of app.py (alongside other imports):

   import qa_cache

2. Add GET /api/cache/stats endpoint:

   ```python
   @app.get("/api/cache/stats")
   async def get_cache_stats():
       """Returns Q&A cache statistics: total pairs and estimated tokens saved."""
       return qa_cache.stats()
   ```

   Expected response shape:
   {
     "cached_pairs": 47,
     "estimated_tokens_saved": 12032
   }

3. Add DELETE /api/cache endpoint:

   ```python
   @app.delete("/api/cache")
   async def clear_cache():
       """Deletes all entries from the Q&A cache. Returns count of deleted pairs."""
       count = qa_cache.clear()
       return {"deleted": count, "message": f"Cleared {count} cached Q&A pairs."}
   ```

   Expected response shape:
   {
     "deleted": 47,
     "message": "Cleared 47 cached Q&A pairs."
   }
