PREREQUISITE: P67-T1 must be merged first. This task depends on:

  wails-app/backend/classifier/llama_server.go → DefaultLlamaServer

════════════════════════════════════════════════════════════════
BACKGROUND / ARCHITECTURE CONTEXT
════════════════════════════════════════════════════════════════

Currently, in wails-app/backend/lib/engine/ (the StealthEngine), audio transcripts from
Whisper STT are emitted in chunks. The engine decides when to send them to the Cloud LLM
using a basic silence/timer heuristic. This causes two problems:
  1. FALSE TRIGGERS: The LLM fires mid-question during a pause.
  2. FRAGMENTED CONTEXT: When an interviewer asks a multi-part question with breaks,
     only the last fragment is sent to the LLM, losing earlier context.

The Rolling Buffer solves both problems:
  - It accumulates ALL transcript chunks since the last LLM trigger into one buffer.
  - It calls Gemma's IsQuestionComplete() every time a new chunk arrives.
  - Only when Gemma returns TRUE does it flush the buffer to the LLM and reset.
  - A hard 45-second failsafe ensures the buffer always flushes eventually.

─── FILE: wails-app/backend/classifier/buffer.go ────────────────────────────────

Package: classifier

STRUCT: QuestionBuffer
Fields:
  - mu               sync.Mutex
  - chunks           []string          // all accumulated transcript chunks since last flush
  - lastChunkAt      time.Time         // timestamp of the most recent chunk addition
  - maxAge           time.Duration     // hard failsafe limit (default: 45 seconds)
  - minChunks        int               // minimum chunks before Gemma is consulted (default: 2)
  - onFlush          func(string)      // callback called with the full aggregated text when flushed
  - classifyFn       func(ctx context.Context, text string) (bool, error)  // injectable for testing

CONSTRUCTOR: NewQuestionBuffer(onFlush func(string)) *QuestionBuffer
  - Set maxAge to 45 * time.Second.
  - Set minChunks to 2.
  - Set classifyFn to classifier.IsQuestionComplete (the real Gemma function from gemma.go).
  - Start an internal goroutine (the "failsafe watchdog") using a time.Ticker that fires
    every 5 seconds. In the watchdog, if the buffer is non-empty AND time.Since(lastChunkAt)
    > maxAge, call flush().

METHOD: (b *QuestionBuffer) AddChunk(chunk string)
  - Acquire lock. Append chunk to b.chunks. Update b.lastChunkAt to time.Now(). Release lock.
  - If len(b.chunks) < b.minChunks, return immediately (not enough context for Gemma yet).
  - Build the full aggregated text: strings.Join(b.chunks, " ").
  - Call b.classifyFn(context.Background(), aggregatedText) in a NEW goroutine to avoid
    blocking the audio pipeline. The goroutine should:
      1. Call classifyFn with a 3-second context timeout.
      2. If result is true → call b.flush().
      3. If error → log it with [Buffer] prefix and continue (do NOT crash).

METHOD: (b *QuestionBuffer) flush() (private)
  - Acquire lock.
  - If chunks is empty, return.
  - Build fullText = strings.Join(b.chunks, " ").
  - Reset b.chunks to empty slice.
  - Release lock.
  - Call b.onFlush(fullText) — this is the callback to trigger the Cloud LLM.

METHOD: (b *QuestionBuffer) Reset()
  - Acquire lock. Clear b.chunks. Release lock.
  - Use this to clear the buffer when the user manually stops a session.

METHOD: (b *QuestionBuffer) Stop()
  - Signal the internal watchdog goroutine to stop (use a done channel).
