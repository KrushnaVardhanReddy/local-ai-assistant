## Task: P30-T2 — Slack Bot Integration

**Project:** BarnOwl AI (Local AI Assistant)
**Phase:** 30 — Platform Integrations
**Task ID:** P30-T2

---

### Goal

Build a Slack Bot that lets any team member interact with BarnOwl AI directly inside Slack. Users can ask questions, get session summaries pushed to a channel, and trigger BarnOwl features via slash commands — without leaving Slack.

---

### Files to Create (ALL NEW — no conflicts)

```
slack-bot/
  app.py               ← Slack Bolt app (Python), the main entry point
  handlers.py          ← Slash command and event handlers
  barnowl_client.py    ← HTTP client that calls the BarnOwl backend API
  requirements.txt     ← slack-bolt, python-dotenv, httpx
  .env.example         ← Template for SLACK_BOT_TOKEN, SLACK_SIGNING_SECRET, BARNOWL_URL
  README.md            ← Setup instructions for Slack App manifest + ngrok
```

---

### Detailed Specification

#### app.py
- Use slack-bolt Python SDK (pip install slack-bolt)
- Start with Socket Mode (no public URL needed for development)
- Register handlers from handlers.py
- Read SLACK_BOT_TOKEN, SLACK_APP_TOKEN, SLACK_SIGNING_SECRET, BARNOWL_URL from .env

#### handlers.py
Implement these slash commands:

1. `/barnowl ask <question>` 
   - POSTs to ${BARNOWL_URL}/chat with { message: question }
   - Replies in-thread with the AI response
   - Shows a "thinking..." message while waiting

2. `/barnowl summarize`
   - POSTs to ${BARNOWL_URL}/session/summary (GET)
   - Posts the last session summary as a formatted Slack Block Kit message
   - Includes key points as bullet list, action items section

3. `/barnowl status`
   - GETs ${BARNOWL_URL}/health
   - Replies with BarnOwl backend status (running, model loaded, etc.)

Also implement an event handler:
- Listen for app_mention events (@BarnOwl in any channel)
- Treat the message text as a question and reply in thread (same as /barnowl ask)

#### barnowl_client.py
- Async HTTP client using httpx
- Methods: ask(question), get_summary(), get_health()
- Timeout: 30 seconds
- On timeout/error: return a friendly error message string

#### Slack Block Kit formatting for summarize response:
```
*📋 BarnOwl Session Summary*
─────────────────
*Key Points:*
• Point 1
• Point 2

*Action Items:*
• Item 1

_Generated by BarnOwl AI_
```

---

### What NOT to do
- Do NOT modify any existing BarnOwl backend files
- Do NOT use webhooks (use Socket Mode so no public URL is needed)
- Do NOT hardcode any tokens
