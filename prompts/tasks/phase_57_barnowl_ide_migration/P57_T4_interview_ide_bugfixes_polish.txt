1. Fix `SessionReport` Empty/Stuck Box & NaN Duration:
   - Root Cause 1: In `InterviewHUD.svelte`:
     - `<SessionReport />` was invoked without `onClose={() => showSessionReport = false}`!
     - `SessionReport.svelte` ALSO has its own fixed backdrop `.report-overlay`, while
       `InterviewHUD.svelte` wrapped it in ANOTHER outer `fixed inset-0` modal wrapper,
       causing double nesting and trapping pointer events!
     - In `InterviewHUD.svelte`, remove the outer wrapper and pass `onClose`:
       ```svelte
       {#if showSessionReport}
         <SessionReport onClose={() => showSessionReport = false} />
       {/if}
       ```
   - Root Cause 2 (Empty body & NaNm):
     - Notice the screenshot: `Session Report 2 questions · NaNm`.
     - In `session.go`: `Export()` was missing `"session_duration_s"`. Add:
       `"session_duration_s": int(time.Since(sm.sessionStartedAt).Seconds())`
     - In `SessionReport.svelte`: When `scorecard` is nil or still generating (or if `session.turns`
       has items but `scorecard` is null), `report-body` only had:
       `{#if isLoading} ... {:else if error} ... {:else if scorecard} ... {/if}`
       If `isLoading` becomes false and `scorecard` is null, the body is COMPLETELY BLANK!
       Add an `{:else}` empty state in `SessionReport.svelte`:
       ```svelte
       {:else}
         <div class="empty-state p-8 text-center text-white/50 flex flex-col items-center gap-3">
           <span class="material-symbols-outlined text-4xl text-primary/60">pending_actions</span>
           <p>No scorecard generated yet for this session.</p>
           {#if session?.turn_count > 0}
             <p class="text-xs text-white/40">Captured {session.turn_count} turn(s). Ask the assistant more questions to evaluate.</p>
           {/if}
           <button class="retry-btn mt-2" onclick={loadReport}>Generate Scorecard</button>
         </div>
       {/if}
       ```
     - In `SessionReport.svelte` header: Guard against undefined `session_duration_s`:
       `{Math.round((session.session_duration_s || 0) / 60)}m` to prevent `NaNm`.
