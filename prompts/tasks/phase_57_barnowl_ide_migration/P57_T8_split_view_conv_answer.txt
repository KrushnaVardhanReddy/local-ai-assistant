TASK: P57-T8 — Split-View Layout: Conversation Left / LLM Answer Right (IDE as Optional Tab)

═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════
Redesign the BarnOwl AI interview layout so that the primary screen is a two-panel split view:
  LEFT PANEL  — Conversation feed (transcript history, suggestion chips, chat input)
  RIGHT PANEL — Live LLM answer / streaming Markdown response

The current center "IDE" editor pane (CodeEditor / workspace file tree) is demoted to an optional
mode, toggled via the ActivityBar `explorer` icon. It should NOT be visible by default.

The key insight: candidates do not need a code editor open all the time. The dominant workflow is:
  1. Hear a question (live transcript appears left).
  2. AI answer streams in on the right.
  3. Optionally, open the IDE to paste code context — then collapse it back.

This eliminates the current awkwardness where the Copilot answer is only visible if the right drawer
is open, while the center pane is wasted space showing an empty editor.

1. DEFAULT LAYOUT (No IDE, Split Conv/Answer):
   - On app load, the default view is TWO side-by-side panels filling the center area:
     a) LEFT: Conversation Panel (width: ~40%, resizable, min 280px)
     b) RIGHT: Answer Panel (width: ~60%, resizable, min 300px)

   - The `CodeEditor` / workspace editor is NOT rendered unless a file is explicitly opened via IDE mode.
   - The ActivityBar still shows its icons:
       `{ id: 'explorer', icon: 'folder_open', label: 'Files' }`   ← toggles file tree + IDE center

   - REMOVE the separate `copilot` ActivityBar icon — the Copilot answer is now always in the RIGHT panel.
   - REMOVE the `keys` ActivityBar icon from the bar itself — hotkeys remain accessible via the header
     toolbar gear/keyboard button in the Conversation Panel header.

2. LEFT PANEL — Conversation Panel (ConvPanel):
   - Header: Small title "Live Session" + status badge (Live/Mock/Mic Off) + RAG context indicator
     + "🔑 Keys" button (toggles hotkeys overlay within this panel).
   - Body (scrollable flex-col, newest items at bottom, auto-scroll):
     · Transcript history items from `wsState.transcriptHistory`:
       - INTERVIEWER items: left-aligned speech bubble (subtle grey/blue tint).
       - CANDIDATE items: right-aligned speech bubble (subtle green tint).
     · Suggestion chips row: pills from `wsState.pendingTranscripts`.
       - Each chip: click → `sendChip(chip)`, dismiss × → `dismissChip(chip.id)`.
       - "Clear All" link if chips > 1.
   - Footer (pinned at bottom):
     · Multi-line textarea (rows=3, min-h-[84px], max-h-[220px], resize-y).
     · Placeholder: "Ask a follow-up or custom prompt... (Shift+Enter for newline)".
     · Submits on Enter (without Shift) via `sendChat(chatText)`.
     · `sendChat` sets `wsState.isThinking = true` and sends to WS/API.
     · Send button aligned bottom-right (icon: `send`).
   - Hotkeys overlay: When "Keys" is toggled, replace the body scroll area with the full hotkeys
     cheat sheet (same content as currently in CopilotDrawer `showHotkeys` mode), scroll within panel.
   - STAR Method & Catch Me Up: Move these quick-action buttons to the Conversation Panel header
     (small icon buttons: `star` for STAR Method, `history` for Catch Me Up).

3. RIGHT PANEL — Answer Panel (AnswerPanel):
   - Header: Title "BarnOwl AI" with `auto_awesome` icon + Clear Cache button (`mop` icon, shows
     cached pair count) + Copy All button.
   - Body (scrollable, newest at bottom, auto-scroll):
     · When `wsState.isThinking && !wsState.response`: animated "Thinking..." pulse card.
     · When `wsState.response` has content: render Markdown with syntax highlighting (Shiki/highlight.js),
       per-code-block copy buttons, streaming cursor if still thinking.
     · Entire answer panel content should be selectable (user-select: text).
   - NO chat input here — this panel is output only.
   - Cache Stats: Small footer chip showing `N Q&A pairs cached` when cache > 0.

4. IDE MODE (Explorer Active):
   - When user clicks the `explorer` ActivityBar icon:
     · The WorkspaceSidebar (file tree) slides in on the LEFT of the ConvPanel.
     · The CENTER pane gets a CodeEditor showing the active document.
     · Layout: [ActBar] | [FileTree] | [ConvPanel] | [AnswerPanel]
     · Clicking `explorer` again collapses both FileTree and CodeEditor, returning to default split.
   - The draggable resizer between ConvPanel and AnswerPanel must still function.
   - The draggable resizer between FileTree and ConvPanel may be added if feasible (low priority).

5. RESIZABLE PANELS:
   - There MUST be a draggable `.resizer-handle` between ConvPanel and AnswerPanel (same implementation
     as the existing resizer in `IDEShell.svelte`).
   - Persist split widths to `localStorage`:
     · Key `barnowl_conv_panel_width` (default: 380px, min 280px, max 60vw).
     · Key `barnowl_answer_panel_width` is derived (flex-grow fills remaining space).

6. HEADER TOOLBAR (unchanged from current):
   - Keep the existing top header toolbar: [BarnOwl AI branding] [Live/Mock badge] [Snip] [Report] [Clear] [Stealth].
   - No changes needed here.

7. SETTINGS PANEL (unchanged):
   - Keep the existing settings slide-out panel triggered by the settings ActivityBar icon.
   - It overlays on the right side (absolute positioned, z-index 50) just as before.

8. MOCK MODE:
   - `mock` ActivityBar icon still calls `handleMockModeToggle()`.
   - Mock badge in top header still shows when `wsState.isMockMode`.

9. RAG CONTEXT BADGE:
   - Show `📄 N context item(s)` badge in the ConvPanel header if `wsState.ragSources.length > 0`
     OR if `includeActiveDocContext && activeDocumentName`.
   - Keep `includeActiveDocContext` state and `activeDocumentName` from `refreshIDEState()`.
