BEHAVIORAL REQUIREMENTS & SPECIFICATION
═══════════════════════════════════════════════════════════════

1. PANEL HEADER:
   - Left side: Title "Live Session" in small caps, muted white.
   - Status badge: show ONE of:
     · "● Live" (green pulse) when `isListening && !isMockMode`
     · "● Mock" (amber pulse) when `isMockMode`
     · "● Mic Off" (red dot, no pulse) otherwise
   - PTT badge: show "🎤 PTT" (green pulsing) when `isPTTHeld`.
   - RAG badge: show "📄 {activeDocumentName}" (green tint) when `includeActiveDocContext && activeDocumentName`.
   - RAG sources badge: show "📎 {ragSources.length} src" when `ragSources.length > 0`.
   - Right side icon buttons (small, 24px):
     · `star` icon — tooltip "STAR Method" — calls `onStarMethod()`.
     · `history` icon — tooltip "Catch Me Up" — calls `onCatchMeUp()`.
     · `keyboard` icon — tooltip "Hotkeys" — toggles `showHotkeys` local state.

2. BODY — NORMAL MODE (scrollable, flex-col, newest at bottom):
   - Scroll container: `overflow-y: auto`, auto-scrolls to bottom when transcriptHistory changes.
   - For each item in `transcriptHistory`:
     a) role === 'interviewer': left-aligned speech bubble
        · Background: rgba(30, 41, 59, 0.6)
        · Border-left: 3px solid rgba(148, 163, 184, 0.4)
        · Label: "Interviewer" in uppercase 9px muted text
     b) role === 'candidate': right-aligned speech bubble
        · Background: rgba(20, 40, 25, 0.6)
        · Border-left: 3px solid rgba(74, 222, 128, 0.4)
        · Label: "You" in uppercase 9px green text
     c) role === 'assistant' or 'ai': AI thinking/answer card
        · When `isThinking && !text`: show animated "Thinking…" pulse (grey dot pulse).
        · When text present: render as pre-formatted text (no Markdown needed here —
          Markdown rendering is AnswerPanel's job). Show truncated preview (max 4 lines)
          with a subtle "→ See full answer" note.
        · Background: rgba(10, 20, 14, 0.7), border-left: 3px solid rgba(74, 222, 128, 0.6).
   - Empty state: when `transcriptHistory.length === 0`, show centered ghost icon
     (`hearing` material icon, 48px, opacity 20%) with text "Waiting for the interview to begin…".

3. SUGGESTION CHIPS (rendered ABOVE footer, scrollable horizontally if needed):
   - Only show when `pendingTranscripts.length > 0`.
   - Each chip: pill button, text truncated at 60 chars.
     · Click: calls `onSendChip(chip)`.
     · × button on right: calls `onDismissChip(chip.id)`.
   - "Clear All" small text link on right if chips > 1: calls `onClearChips()`.

4. BODY — HOTKEYS MODE (when `showHotkeys === true`):
   - Replace the scroll body with a full scrollable hotkeys cheat sheet.
   - Content: EXACT same hotkeys content as currently in CopilotDrawer.svelte's hotkeys view.
     Copy the full hotkeys table/list from CopilotDrawer.svelte (read that file for the current content).
   - Header icon `keyboard` should toggle this mode on/off (active state: green tint).

5. FOOTER — CHAT INPUT (always pinned at bottom):
   - Multi-line `<textarea>`:
     · `rows=3`, `min-height: 84px`, `max-height: 220px`, `resize: vertical`
     · placeholder: "Ask a follow-up… (Shift+Enter for newline)"
     · On `Enter` (without Shift): calls `onSendChat(chatText.trim())` then clears input.
     · On `Shift+Enter`: inserts newline (default textarea behavior).
   - Send button: bottom-right, `send` material icon, calls `onSendChat(chatText.trim())`.
   - Disable both textarea and button when `isThinking === true` (show subtle loading state).
