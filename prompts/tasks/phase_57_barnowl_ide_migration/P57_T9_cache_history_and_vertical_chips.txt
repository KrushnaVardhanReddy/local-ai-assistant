SECTION 2: AnswerPanel.svelte — Cache History State
═══════════════════════════════════════════════════════════════
ADD state variables for the History View:
```typescript
let showHistory = $state(false);
let cacheItems = $state<any[]>([]); // To store the fetched cache history
```

ADD a function to fetch the cache history:
```typescript
// You may need to import GetCacheItems from wailsjs/go/main/App
async function toggleHistory() {
  if (!showHistory) {
    try {
      // Fetch the items from the backend
      const items = await window.go.main.App.GetCacheItems();
      cacheItems = items || [];
    } catch (e) {
      console.error('Failed to fetch cache items:', e);
    }
  }
  showHistory = !showHistory;
}
```

      {:else}
        <div class="history-list">
          {#each cacheItems as item}
            <button class="history-item" onclick={() => {
              // When an old question is clicked, we just show its cached answer
              // and close the history view. We can temporarily override the main response,

              showHistory = false;
            }}>
              <div class="history-q">{item.Question}</div>
              <div class="history-meta">
                <span>Tokens saved: ~{item.TokensSaved || 250}</span>
              </div>
            </button>
          {/each}

      {/if}
    </div>
  {:else}
