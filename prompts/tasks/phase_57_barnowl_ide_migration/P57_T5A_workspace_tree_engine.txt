TASK: P57-T5A — Backend Engine File Extensions & Reusable Workspace Tree Normalization

═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════
Fix backend file parsing and workspace tree node components so that directories containing
code/notes can be opened and displayed with proper folder expanding/collapsing.

This task owns ONLY the backend engine workspace logic and the reusable workspace tree
components under `wails-app/frontend/src/lib/components/workspace/`. It has zero overlap
with the drawers or HUD files.

═══════════════════════════════════════════════════════════════
BEHAVIOR & BUTTON EXPECTATIONS
═══════════════════════════════════════════════════════════════

1. [Supported File Extensions] (`wails-app/core/engine/workspace.go`):
   - Role: Allows the user to load folders containing notes and code into the workspace.
   - Current Bug: `allowedExtensions` is strictly limited to `.txt`, `.md`, `.pdf`, `.pptx`.
     Opening any folder with code files (.go, .py, .ts, etc.) returns:
     `"directory ... does not contain valid document files"`.
   - Expected: Expand `allowedExtensions` to support standard notes and programming files.

2. [Native Open File Dialog Filters] (`wails-app/app.go`):
   - Role: Shows supported file extensions in the native file picker dialog.
   - Current Bug: Restricts file dialog filter pattern to `*.txt;*.md;*.pdf;*.pptx`.
   - Expected: Update `PromptOpenFile` filters to include code and document extensions as well as `*.*`.

3. [Folder Expansion & Chevron Toggle] (`FileTreeNode.svelte`):
   - Role: Displays folder chevron (▶ / ▼) and expands/collapses child directories.
   - Current Bug: The Go backend (`driving.FileNode`) serializes `isDir: bool`, but Svelte
     components check `node.isDirectory`. As a result, folders are treated as regular files,
     preventing expansion and showing incorrect file icons.
   - Expected: `FileTreeNode.svelte` defensively computes `isDir`:
     `const isDir = Boolean(node.isDirectory ?? (node as any).isDir);`
     and ensures clicking the folder toggles `isExpanded` and renders child nodes in `.children`.

4. [File Tree Selection] (`FileTreeNode.svelte` & `FileTree.svelte`):
   - Role: Clicking a file triggers `onSelect(node)` to open that file in the workspace.
   - Expected: Clicking a non-directory node calls `onSelect(node)` with the node object.

5. [Sidebar Action Buttons] (`WorkspaceSidebar.svelte`):
   - Role: Header action buttons for "FILE" (`note_add`) and "FOLDER" (`create_new_folder`).
   - Expected: Clicking "FILE" invokes `onOpenFile()`. Clicking "FOLDER" invokes `onOpenFolder()`.
