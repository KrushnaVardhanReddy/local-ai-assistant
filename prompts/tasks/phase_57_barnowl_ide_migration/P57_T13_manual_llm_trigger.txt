═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════
PREREQUISITES: P57-T10, P57-T11, AND P57-T14 must be merged before starting this task.
This task has the most file overlap — it must come AFTER T11 and T14.

Add a "Manual Mode" toggle. In manual mode, incoming transcript bubbles accumulate
in the left panel but do NOT automatically trigger an LLM call. The user must
explicitly click a bubble to send it to the LLM (or retrieve from cache if already answered).

In "Auto Mode" (default / current behavior), every accepted transcript immediately
fires the LLM pipeline as it does today.

SECTION 1: app.go — Expose ManualMode Toggle to Frontend
═══════════════════════════════════════════════════════════════
The auto-sending of transcripts to the LLM is triggered in the Go engine when
the STT emits a transcript event. We need a way for the frontend to tell the
backend to stop auto-processing.

Append this new method to the end of `wails-app/app.go`:

```go
// SetManualMode enables or disables automatic LLM processing of transcripts.
// When manualMode is true, transcripts will still be emitted to the frontend via
// on_transcript events, but the engine will NOT automatically queue them for LLM processing.
func (a *App) SetManualMode(enabled bool) {
    if a.engine != nil {
        a.engine.SetManualMode(enabled)
        log.Printf("🎛️ Manual mode set to: %v", enabled)
    }
}
```

Then look inside `wails-app/core/engine/` for the StealthEngine struct and add
a `SetManualMode(bool)` method and a `manualMode bool` field to it.
When `manualMode` is true, the engine should skip queuing the LLM call when a
transcript arrives. The transcript event should still be emitted to the frontend.

═══════════════════════════════════════════════════════════════
SECTION 2: ws.svelte.ts — New manualMode State
═══════════════════════════════════════════════════════════════
Add a `manualMode` flag to `wsState`:
```typescript
export const wsState = $state({
  // ...existing fields...
  manualMode: false,
});
```

Add a toggle function:
```typescript
export async function toggleManualMode(): Promise<void> {
  wsState.manualMode = !wsState.manualMode;
  try {
    await (window as any).go.main.App.SetManualMode(wsState.manualMode);
  } catch (e) {
    console.error('Failed to set manual mode:', e);
    wsState.manualMode = !wsState.manualMode; // Rollback on error
  }
}
```
