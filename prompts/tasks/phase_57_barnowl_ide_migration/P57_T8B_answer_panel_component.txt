BEHAVIORAL REQUIREMENTS & SPECIFICATION
═══════════════════════════════════════════════════════════════

1. PANEL HEADER:
   - Left side: `auto_awesome` material icon (green, 18px) + title "BarnOwl AI" (bold, white).
   - Right side icon buttons (small, 24px):
     · `content_copy` icon — tooltip "Copy Answer" — calls `onCopyAll()`.
       On click: copies `response` to clipboard via `navigator.clipboard.writeText(response)`,
       briefly shows checkmark icon for 1.5s as feedback.
     · `mop` icon — tooltip "Clear Cache ({cacheCount} pairs)" — calls `onClearCache()`.
       Show badge number `cacheCount` in a tiny circle on the icon if `cacheCount > 0`.
   - Header bottom border: 2px solid rgba(74, 222, 128, 0.3) to signal "AI output zone".

2. BODY — EMPTY STATE:
   - When `!isThinking && !response`:
     · Centered ghost: `auto_awesome` material icon (64px, opacity 15%, green tint).
     · Text: "Waiting for a question…" (opacity 30%).

3. BODY — THINKING STATE:
   - When `isThinking && !response`:
     · Show animated "Thinking…" card:
       - Pulsing gradient background (subtle dark green shimmer).
       - Three animated dots (bounce animation offset by 0.1s each).
       - Text: "BarnOwl is thinking…"
     · Occupy the full body area centered.

4. BODY — RESPONSE (Markdown rendered):
   - When `response` has content (even if `isThinking` is still true — streaming in progress):
     · Render Markdown to HTML.
     · Use the same Markdown rendering approach as currently in `CopilotDrawer.svelte`.
       Read `CopilotDrawer.svelte` to identify the exact import and function used
       (e.g., `marked`, `marked-shiki`, or a custom `renderMarkdown` utility).
     · Copy the import pattern exactly.
     · Per code block: add a small "Copy" button in the top-right corner of each `<pre>` block.
       On click: copies only that block's code to clipboard.
     · Streaming cursor: when `isThinking === true` and response is non-empty, append a blinking
       `▌` cursor character after the last rendered character.
     · Auto-scroll: scroll to bottom whenever `response` changes length (new content streaming in).
       Only auto-scroll if the user has NOT manually scrolled up (preserve manual scroll position).
     · Text should be user-selectable (`user-select: text`).

5. FOOTER — CACHE & RAG SOURCES:
   - Small footer bar (height 28px), border-top 1px solid rgba(255,255,255,0.06).
   - Left: if `cacheCount > 0`: grey pill "💾 {cacheCount} pairs cached".
   - Right: if `ragSources.length > 0`: grey pill "📎 {ragSources.length} context source(s)".
   - If neither: footer is hidden (height 0, display none).

- Auto-scroll with scroll-lock detection:
  ```typescript
  let scrollEl: HTMLDivElement;
  let userScrolledUp = $state(false);

  function onScroll() {
    const atBottom = scrollEl.scrollHeight - scrollEl.scrollTop - scrollEl.clientHeight < 40;
    userScrolledUp = !atBottom;
  }

  $effect(() => {
    response; // reactive dependency
    if (!userScrolledUp && scrollEl) {
      scrollEl.scrollTop = scrollEl.scrollHeight;
    }
  });
  ```
