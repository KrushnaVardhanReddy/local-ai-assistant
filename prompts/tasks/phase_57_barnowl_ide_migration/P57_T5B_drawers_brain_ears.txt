═══════════════════════════════════════════════════════════════
BEHAVIOR & BUTTON EXPECTATIONS
═══════════════════════════════════════════════════════════════

───────────────────────────────────────────────────────────────
GROUP 1: THE BRAIN DRAWER (`BrainDrawer.svelte`)
───────────────────────────────────────────────────────────────
1. [STAR Method Action Button] (`button.action-btn:has-text("STAR")`):
   - Role: Primes the AI assistant to format its next answer using Situation, Task, Action, Result.
   - Expected:
     - Sends prompt override: `sendChat("Format your next response using the STAR method (Situation, Task, Action, Result).")`.
     - Sets `starPrimed = true`.
     - Displays pulsing indicator: `STAR Method Primed`.
     - Clears indicator after 15 seconds.
     - Adds visual highlight class `.star-primed` on the button while active.

2. [Catch Me Up Button] (`button[title="Catch me up"]`):
   - Role: Requests an instant summary of recent conversational context.
   - Expected:
     - Sends prompt: `sendChat("Please catch me up on the current context of the interview or conversation.")`.
     - Triggers AI response streaming into the response area.

3. [Clear Cache Button] (`button[title="Clear cache"]`):
   - Role: Flushes the embedded semantic Q&A vector cache.
   - Expected:
     - Calls `App.ClearCache()` or `POST /api/cache/clear`.
     - Resets displayed cache items count to 0.
     - Shows transient spinner/disabled state while clearing.

4. [AI Response Markdown & Auto-Scroll]:
   - Role: Displays formatted markdown AI hints, code snippets, and explanations.
   - Expected: Renders markdown, code blocks with copy/syntax styles, and auto-scrolls to bottom
     as tokens stream in.

───────────────────────────────────────────────────────────────
GROUP 2: LIVE EARS DRAWER (`LiveEarsDrawer.svelte`)
───────────────────────────────────────────────────────────────
5. [Custom Prompt Input & Submit] (`textarea` + Enter / Submit):
   - Role: Allows the user to type and send an ad-hoc whisper/instruction to the AI.
   - Expected:
     - Pressing `Enter` (without Shift) calls `sendChat(chatText)`.
     - Clears the textarea.
     - Triggers thinking state in the assistant.

6. [Pending Suggestion Chips Click] (`.chip button.text-xs`):
   - Role: Candidate clicks an intercepted question chip to force instant answer generation.
   - Expected:
     - Calls `sendChip(chip)`.
     - Removes that chip from `wsState.pendingTranscripts`.
     - Sends the question text to the assistant.

7. [Dismiss Chip Button] (`.chip button[aria-label="Dismiss"]`):
   - Role: Discards an unwanted suggestion chip.
   - Expected: Calls `dismissChip(chip.id)`, removing it from the pending list.

8. [Clear All Chips Button] (`button:has-text("Clear All")`):
   - Role: Flushes all pending suggestion chips at once.
   - Expected: Calls `clearAllChips()`, clearing `wsState.pendingTranscripts`.

9. [Transcript Auto-Scroll & Speaker Tags]:
   - Role: Displays live interview speech.
   - Expected: Auto-scrolls to newest line, distinguishes `Speaker` (interviewer) from `You` (candidate).
