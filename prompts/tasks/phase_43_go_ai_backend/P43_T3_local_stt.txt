TITLE: P43-T3 Local STT in Go
OBJECTIVE
Replace `faster-whisper` (Python) by integrating `whisper.go` (CGO bindings for whisper.cpp) for offline Speech-to-Text inference.

INSTRUCTIONS
1. Inside `wails-app/backend/`, create `stt.go`.
2. Add the dependency for `whisper.go` or a suitable CGO wrapper for whisper.cpp.
3. Implement a function to load the ggml/gguf Whisper model.
4. Implement `TranscribeAudio(audioPath string) string` that takes a path to a WAV file, processes it through whisper.cpp, and returns the transcribed text.
