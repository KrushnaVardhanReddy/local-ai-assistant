TASK: P43-T3 — Local STT in Go

═══════════════════════════════════════════════════════════════
BACKGROUND & CONTEXT
═══════════════════════════════════════════════════════════════

To replace the Python `faster-whisper` sidecar, we will integrate `whisper.go` (CGO bindings for whisper.cpp) directly into our Go backend for fast, offline speech-to-text inference.

═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════

1. INTEGRATE WHISPER
   - Inside `wails-app/backend/`, create `stt.go`.
   - Add the dependency for `whisper.go` or a suitable CGO wrapper for whisper.cpp.
   - Implement a function to load the local ggml/gguf Whisper model from disk.

2. TRANSCRIBE AUDIO
   - Implement `TranscribeAudio(audioPath string) string`.
   - This function should take a path to a WAV file, process it through the whisper.cpp bindings, and return the transcribed text.
