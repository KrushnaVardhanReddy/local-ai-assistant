Implement the Product-Led Growth (PLG) Freemium model. Free users should
get unlimited local transcription (faster-whisper) but NO access to the 
Cloud LLM endpoints (chat, summary, CRM sync).

If a Free user connects via WebSocket and tries to use a Cloud LLM:
1. Reject the LLM processing.
2. Send a WebSocket message back: {"type": "upgrade_required", "message": "Cloud LLMs require a Pro subscription."}
3. Allow them to continue using STT locally.
