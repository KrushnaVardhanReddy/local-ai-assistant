TASK: P42-T5 — Cloud Auth UI (Login & Registration)

═══════════════════════════════════════════════════════════════
BACKGROUND & CONTEXT
═══════════════════════════════════════════════════════════════

For users running the Cloud Edition (SaaS mode), they need an interface to create an account and log in. We already have the backend logic in `auth.svelte.ts` configured for Supabase Auth, but we lack the Svelte UI components (modals/pages) for users to type in their email/password and actually register.

═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════

1. ADD REGISTRATION LOGIC
   - In `wails-app/frontend/src/lib/auth.svelte.ts`, implement a new `signUp(email, password)` function using `supabase.auth.signUp()`.

2. BUILD AUTH UI COMPONENT
   - Create a new component `wails-app/frontend/src/lib/components/AuthModal.svelte` (or integrate it into an existing Settings/Login page).
   - It should have a clean, modern UI for "Sign In" and "Create Account".
   - It should handle loading states, success messages, and display any Supabase Auth errors gracefully.
   - When the user successfully logs in or registers, the modal should close and the UI should update their session state.
