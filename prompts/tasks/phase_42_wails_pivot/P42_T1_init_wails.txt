TITLE: P42-T1 Init Wails Project
OBJECTIVE
Initialize a new Wails Go project using the Svelte-TS template to serve as the new unified codebase.

INSTRUCTIONS
1. Use the Wails CLI to generate a new project in the root directory named `wails-app`.
   - Command: `wails init -n wails-app -t svelte-ts`
2. DO NOT delete the existing `frontend/` or `src-tauri/` directories yet.
3. Make sure the generated `wails-app/main.go` and `wails.json` are committed.
