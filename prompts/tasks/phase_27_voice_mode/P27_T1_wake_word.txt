TASK: P27-T1 — Wake Word Detection ("Hey Owl")

═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════
Integrate Picovoice Porcupine wake word detection so BarnOwl AI
can listen passively in the background and activate only when the
user says "Hey Owl" — exactly like Alexa or Google Home.

The wake word engine runs at near-zero CPU cost and listens 24/7
without sending any audio to the internet. This makes BarnOwl AI
a safe, always-available enterprise voice assistant.

Key behaviors:
  1. Add a new `backend/wake_word.py` module that wraps Porcupine.
  2. The module runs on a dedicated background thread separate from
     the main audio capture loop.
  3. When the wake word is detected, it emits a `wake_word_detected`
     event by sending a WebSocket message `{"type": "wake_word_triggered"}`.
  4. Add a config flag `WAKE_WORD_ENABLED=false` (off by default) so
     existing users are unaffected until they opt in.
  5. Add a "Voice Mode" toggle to Settings.svelte to enable/disable it.

═══════════════════════════════════════════════════════════════
CONSTRAINTS & RULES
═══════════════════════════════════════════════════════════════
- Use `pvporcupine` (Picovoice Porcupine Python SDK). Add to requirements.txt.
  Use the FREE built-in keywords — "hey google", "alexa", "jarvis" are examples.
  For a custom "hey owl" keyword, we need a Picovoice account. Use "jarvis"
  as the DEFAULT wake word for now (it is a built-in free keyword).
- The wake word thread must be COMPLETELY isolated from the main STT thread.
  It should use a separate `sounddevice.InputStream` on the same mic.
- If `pvporcupine` is not installed or `PICOVOICE_ACCESS_KEY` is missing,
  the module must silently disable itself (no crash, no error).
- Do NOT modify `audio_listener.py`. The wake word detector is a standalone module.
