TASK: P27-T2 — Text-to-Speech (TTS) for Voice Conversational Mode

═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════
Add Text-to-Speech (TTS) output so BarnOwl AI can speak LLM responses
aloud — completing the Voice-In / Voice-Out conversational loop started
by P27-T1 (wake word detection).

When TTS mode is active, instead of just streaming text to the UI panel,
the LLM's response is also converted to speech and played through the
default system speakers.

Key behaviors:
  1. Create a new `backend/tts.py` module with a `TTSEngine` class.
  2. Default TTS engine: Microsoft `edge-tts` (free, neural voices, no API key).
     Premium TTS engine (optional, Lifetime BYOK tier): OpenAI TTS API.
  3. After streaming each LLM response sentence (split on `.`, `!`, `?`),
     call `tts.speak(sentence)` async to avoid blocking the stream.
  4. TTS audio is played server-side using `sounddevice.play()` on the
     default output device.
  5. Add a `TTS_ENABLED=false` config flag. Default off.
  6. While TTS is speaking, set a `tts_speaking` busy-guard so the STT
     pipeline ignores the speaker audio (avoids the AI hearing itself).

═══════════════════════════════════════════════════════════════
CONSTRAINTS & RULES
═══════════════════════════════════════════════════════════════
- Use `edge-tts` library (pip install edge-tts). Add to requirements.txt.
- `edge-tts` is async — use `asyncio` natively. Do NOT block the WS thread.
- Sentence splitting: use a simple regex `re.split(r'(?<=[.!?])\s+', text)`.
  Do NOT use NLTK or any heavy NLP library.
- The `tts_speaking` flag must integrate with the existing busy-guard in
  `backend/smart_filter.py`. Add a new check: `if tts_speaking: drop audio`.
- If TTS is playing and the wake word fires again (P27-T1), interrupt
  TTS immediately (cancel the current audio playback task).
- Default voice: `en-US-AriaNeural` (clear, professional female voice).
  Make this configurable via `TTS_VOICE` env var.
