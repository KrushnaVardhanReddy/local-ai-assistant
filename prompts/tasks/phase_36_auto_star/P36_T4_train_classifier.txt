TASK: P36-T4 — Train a custom sklearn classifier on SmolLM2 embeddings for question routing

═══════════════════════════════════════════════════════════════
BACKGROUND & CONTEXT
═══════════════════════════════════════════════════════════════

`classify_question(transcript)` in `backend/local_intelligence.py` currently
uses cosine similarity against hand-crafted anchor embeddings, but SmolLM2-135M's
generic embeddings are not separable enough for fine-grained categories.

The fix: use SmolLM2 as a FROZEN FEATURE EXTRACTOR and train a tiny sklearn
Logistic Regression classifier on top of its embeddings. This is the same pattern
used in production ML systems (BERT + classifier head, GPT embeddings + linear probe).

The trained model is a tiny .pkl file (~10KB). SmolLM2 itself is NOT retrained.

═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════

1. Write a training script at `scripts/train_classifier.py` that:
   - Defines a labeled dataset of ~60 example interview questions (10 per category)
   - Loads SmolLM2 via LocalIntelligence and calls `.encode()` on each example
   - Trains a `sklearn.linear_model.LogisticRegression` on those embeddings
   - Saves the trained model to `backend/models/question_classifier.pkl`
   - Prints per-class accuracy using cross-validation

2. Update `backend/local_intelligence.py` to:
   - Load `question_classifier.pkl` at startup (if it exists) using `pickle`
   - In `classify_question()`, replace the cosine similarity approach with:
     a. Call `self.encode(transcript)` to get the embedding vector
     b. Call `self._classifier.predict([embedding])[0]` to get the category
   - Fall back to "conceptual" if the classifier is not loaded or fails

3. Add `scikit-learn` to `backend/requirements.txt`

4. Run the training script as part of the task to generate the .pkl and commit it.

TRAINING SCRIPT STRUCTURE (scripts/train_classifier.py)
═══════════════════════════════════════════════════════════════

```python
#!/usr/bin/env python3
"""
Train a Logistic Regression classifier on SmolLM2 embeddings.
Run from the project root: python3 scripts/train_classifier.py
"""
import sys, os, pickle
sys.path.insert(0, os.path.join(os.path.dirname(__file__), "..", "backend"))

from local_intelligence import get_local_intelligence
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import cross_val_score
import numpy as np

DATASET = {
    "behavioral": [ ... ],
    "coding": [ ... ],
    "system_design": [ ... ],
    "conceptual": [ ... ],
    "opinion": [ ... ],
    "noise": [ ... ],
}

def main():
    li = get_local_intelligence()
    X, y = [], []
    for label, examples in DATASET.items():
        for text in examples:
            vec = li.encode(text)
            if vec:
                X.append(vec)
                y.append(label)

    X = np.array(X)
    clf = LogisticRegression(max_iter=1000, C=1.0)
    scores = cross_val_score(clf, X, y, cv=5)
    print(f"Cross-val accuracy: {scores.mean():.2%} ± {scores.std():.2%}")

    clf.fit(X, y)
    out_path = os.path.join(os.path.dirname(__file__), "..", "backend", "models", "question_classifier.pkl")
    with open(out_path, "wb") as f:
        pickle.dump(clf, f)
    print(f"Saved classifier to {out_path}")

if __name__ == "__main__":
    main()
```
