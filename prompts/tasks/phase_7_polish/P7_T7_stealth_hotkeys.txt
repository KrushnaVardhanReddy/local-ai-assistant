TASK: P7-T7 — Advanced Stealth Hotkeys & Cheatsheet UI

═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════
Implement advanced, mouse-less hotkeys for power users to navigate 
and interact with the assistant entirely via the keyboard. Include 
an in-app stealthy UI "cheatsheet" so users don't forget the hotkeys.

Key behaviors:
  1. Add a small "⌨️" (keyboard) icon button to the top toolbar in 
     `Assistant.svelte`.
  2. Clicking this button opens a sleek, glassmorphism modal/overlay 
     *inside* the main window. Because it's inside the main window, 
     it automatically inherits our Tauri `WDA_EXCLUDEFROMCAPTURE` 
     stealth protections.
  3. The cheatsheet UI should display a clean table of the active hotkeys:
     - `Ctrl+Shift+Space` — Push to Talk
     - `Ctrl+Shift+S` — Screenshot Vision
     - `Ctrl+Shift+1` through `6` — Send Transcript Chip
     - `Ctrl+Shift+Up/Down` — Scroll Answer
  4. Register the new global hotkeys (`Ctrl+Shift+1` through `6`) in 
     Tauri (`main.rs`) and emit them to the frontend.
  5. In `Assistant.svelte` (or `ws.svelte.ts`), listen for these hotkey 
     events and trigger the `sendPendingTranscript(index)` function 
     (e.g., pressing `Ctrl+Shift+2` sends the 2nd pending transcript 
     chip to the LLM).

═══════════════════════════════════════════════════════════════
CONSTRAINTS & RULES
═══════════════════════════════════════════════════════════════
- The UI modal must live in `Assistant.svelte` so it stays hidden from 
  screen sharing. Do NOT spawn a new Tauri window.
- The modal should look premium: use `bg-surface-variant/90`, 
  `backdrop-blur-md`, subtle borders, and clear typography.
- Global Hotkeys must be registered in Rust (`main.rs`) using the 
  existing `global-shortcut` plugin.

═══════════════════════════════════════════════════════════════

═══════════════════════════════════════════════════════════════

   - Listen for the `hotkey_transcript_X` Tauri events using `listen()`.
   - When received, call the existing `sendTranscriptChip(index)` logic
