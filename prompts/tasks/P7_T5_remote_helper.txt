TASK: P7-T5 — Remote Helper Mode (Cloudflare Tunnel Broadcast)

═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════
Enable a "Remote Helper Mode" where a friend can securely connect to the assistant
over the internet to view the live transcript and control the UI (scroll, clear history,
trigger searches) on behalf of the candidate. This eliminates the need for the
candidate to touch their mouse or keyboard during an interview, making the stealth
assistant truly undetectable.

═══════════════════════════════════════════════════════════════
CONSTRAINTS & RULES
═══════════════════════════════════════════════════════════════
- The FastAPI backend must serve the compiled Svelte frontend statically on a new route (e.g., `GET /helper/*`).
- The WebSocket connection in `ws.ts` must use relative URLs or automatically detect if it is running in a browser (`window.location.host`) versus the Tauri desktop app (`127.0.0.1:8000`) so the remote helper's browser can connect back to the FastAPI server.
- Add a startup script `scripts/start_remote.sh` that launches Cloudflare `cloudflared` to expose the FastAPI server securely over a free `trycloudflare.com` tunnel.

═══════════════════════════════════════════════════════════════
CONTEXT — EXISTING REPO LAYOUT & ARCHITECTURE
═══════════════════════════════════════════════════════════════
- `backend/app.py` (P3-T2): The main FastAPI server. Add `fastapi.staticfiles.StaticFiles` mounting.
- `frontend/vite.config.ts`: Svelte is compiled to `frontend/dist/`. FastAPI needs to serve from this directory.
- `frontend/src/lib/ws.ts`: The WebSocket client. Needs dynamic host resolution.
- `ws_manager` in FastAPI: Already broadcasts to all connected clients. No backend logic change needed for multi-client support!

═══════════════════════════════════════════════════════════════
DELIVERABLES
═══════════════════════════════════════════════════════════════

1. FILE: backend/app.py (MODIFY)
   a. Import `StaticFiles` from `fastapi.staticfiles`.
   b. Add a route to serve the built Svelte app:
      ```python
      import os
      frontend_dist = os.path.join(os.path.dirname(__file__), "../frontend/dist")
      if os.path.exists(frontend_dist):
          app.mount("/helper", StaticFiles(directory=frontend_dist, html=True), name="helper")
      ```

2. FILE: frontend/src/lib/ws.ts (MODIFY)
   a. Update the backend URL resolution so it works in both Tauri and standard web browsers:
      ```typescript
      // If we are in a normal browser (remote helper), use the current host.
      // If we are in Tauri (tauri://localhost), fallback to 127.0.0.1:8000.
      const isBrowser = window.location.protocol.startsWith('http');
      const host = isBrowser ? window.location.host : '127.0.0.1:8000';
      const wsProtocol = window.location.protocol === 'https:' ? 'wss:' : 'ws:';
      
      const wsUrl = `${wsProtocol}//${host}/ws`;
      const apiUrl = `${window.location.protocol}//${host}`;
      ```
   b. Ensure all `fetch()` calls in the frontend use `apiUrl` instead of hardcoded `127.0.0.1`.

3. FILE: scripts/start_remote.sh (CREATE)
   a. Create a bash script that checks if `cloudflared` is installed. If not, print install instructions (`curl -L --output cloudflared ...`).
   b. Run the FastAPI server in the background: `uvicorn backend.app:app --port 8000 &`
   c. Run the tunnel: `cloudflared tunnel --url http://127.0.0.1:8000`
   d. The script should explicitly instruct the user to copy the `https://*.trycloudflare.com` URL and send it to their remote helper, who must append `/helper` to the URL.

4. Build and Test:
   a. Run `npm run build` in `frontend/` to generate the `dist` folder.
   b. Run the FastAPI server.
   c. Open your normal web browser to `http://127.0.0.1:8000/helper`.
   d. Speak into the mic (via the Tauri app or backend listener) — verify the transcript streams to the browser.
   e. Click "Clear" in the browser — verify the Tauri app clears instantly.

IMPLEMENTATION HINTS
═══════════════════════════════════════════════════════════════
- The beauty of this task is that it relies purely on existing architecture. The WebSocket manager in FastAPI naturally supports N connected clients and broadcasts to all of them simultaneously.
- When compiling Svelte for static serving under a subpath like `/helper`, ensure `vite.config.ts` or Svelte settings (if any base path config is needed) handle relative asset paths properly so CSS/JS load correctly.
