TASK: P7-T6 — E2E Test Suite (Backend API + Frontend in Isolation)

═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════
Create a two-layer automated test suite to validate the complete
Local AI Assistant pipeline without requiring a running Tauri binary:
  Layer 1: pytest-based async tests for all FastAPI backend endpoints.
  Layer 2: Playwright tests for the Svelte frontend running in browser mode (no Tauri).

The Tauri binary (stealth, hotkeys, keychain) is validated manually.

═══════════════════════════════════════════════════════════════
CONSTRAINTS & RULES
═══════════════════════════════════════════════════════════════
- No mocks for the core pipeline. Use a real (but lightweight) test fixture.
- Tests must be runnable with a single command each:
    Layer 1: `pytest tests/`
    Layer 2: `npx playwright test`
- All tests must be idempotent — safe to re-run without manual cleanup.
- Do NOT test Tauri IPC, OS keychain, or stealth hooks — those are out of scope.
- Use `TAURI_ENV_DEBUG_VISIBLE=true` note in README — Playwright needs the window visible.

═══════════════════════════════════════════════════════════════

═══════════════════════════════════════════════════════════════
IMPLEMENTATION HINTS
═══════════════════════════════════════════════════════════════
- For `test_upload_txt`, use `httpx.AsyncClient` with `files={"file": ("test.txt", b"Hello world RAG test content", "text/plain")}`.
- The conftest `app_client` fixture should use `asgi_transport=httpx.ASGITransport(app=app)` so no real server process is needed.
- For Playwright, `data-testid` attributes are the most stable selectors — avoid CSS class selectors since Svelte scopes them.
- The `webServer.reuseExistingServer` option in Playwright config prevents re-starting the dev server if already running.
