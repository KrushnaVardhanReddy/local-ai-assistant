TASK: P6-T1 — SvelteKit Web App (Landing Page + Dashboard Scaffold)

═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════
Build the SvelteKit web application that serves as the public marketing site AND the
authenticated user dashboard for the BYOK SaaS tier. This is a separate app from
the Tauri desktop client — it runs in a browser and is deployed to a hosting platform.

═══════════════════════════════════════════════════════════════
CONSTRAINTS & RULES
═══════════════════════════════════════════════════════════════
- Use SvelteKit (latest stable) with TypeScript. NOT the Tauri frontend.
- Vanilla CSS only — no Tailwind, no UI library. Dark theme matching the desktop app.
- Auth-protected routes MUST check the session server-side in `+page.server.ts` — do NOT rely on client-side checks alone.
- No placeholder lorem ipsum — write real product copy for this specific project.
- `npm run dev` must work after `npm install` and setting env vars in `.env.local`.

═══════════════════════════════════════════════════════════════
CONTEXT — EXISTING REPO LAYOUT & ARCHITECTURE
═══════════════════════════════════════════════════════════════
- This is a NEW `web/` directory at the repo root — separate from `frontend/` (Tauri app) and `backend/` (Python).
- Auth is handled by Supabase (set up in P6-T2). This task creates the pages; the auth logic module comes next.
- The dashboard pages will be protected with `redirect(303, '/login')` if no session exists.
- Design tokens (match desktop app):
    Background: #0d0d0d  |  Surface: rgba(255,255,255,0.04)
    Accent: #7c3aed      |  Text: #e2e8f0  |  Muted: #64748b
    Font: Inter          |  Border: 1px solid rgba(255,255,255,0.08)

   export async function load({ locals }) {
       if (!locals.session) throw redirect(303, '/login')
       return { user: locals.user }
   }
