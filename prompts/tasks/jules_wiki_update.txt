═══════════════════════════════════════════════════════════════
KEY ARCHITECTURE CHANGES TO DOCUMENT
═══════════════════════════════════════════════════════════════
1. **Wails + Go Native Desktop:** The app has migrated from web/Tauri to a pure native desktop application using Wails v2 (Go backend, Svelte 5 frontend).
2. **AI Backend Pipeline:** The backend is written in pure Go. It captures system audio natively via loopback, handles Voice Activity Detection (VAD), and runs speech-to-text (STT) via Groq or local Whisper bindings.
3. **Caching & DB:** Caching has been moved to SQLite (using `sqlite-vec` for RAG and vector search) and a new Cache Manager UI exists in the right panel.
4. **Cloud & Local LLMs:** The system supports a hybrid approach: local models (via Ollama/llama.cpp) or cloud models (Groq, Gemini, OpenRouter, Cloudflare Workers AI) configurable via `.env.local`.
