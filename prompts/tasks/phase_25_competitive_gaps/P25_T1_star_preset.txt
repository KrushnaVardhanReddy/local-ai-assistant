TASK: P25-T1 — STAR Method Preset Button (Competitive Gap vs Parakeet AI)

═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════
Add a "STAR" preset button to the top toolbar in Assistant.svelte.
When clicked, it sends a hidden chat message to the LLM instructing it
to format its NEXT response using the STAR method (Situation, Task,
Action, Result) — the behavioral interview framework used by top-tier
tech companies like Google, Meta, and Amazon.

This is a direct competitive gap vs Parakeet AI which has STAR
structuring built-in. We are adding it as a one-click toolbar toggle.

Key behaviors:
  1. A "STAR" button appears in the toolbar between the vision/screenshot
     button and the session report button.
  2. When clicked, it sends a silent preflight chat message:
     "For your next response only, structure your answer using the STAR
      method: Situation → Task → Action → Result. Keep each section
      concise and use bold section headers."
  3. The button visually activates (glowing accent state) for 3 seconds
     then resets — indicating "STAR mode is primed for the next answer".
  4. A small tooltip on hover reads: "Prime next answer with STAR format".
  5. This is FRONTEND ONLY — the message is sent via the existing
     sendChat() function which already bypasses all backend filters.

IMPLEMENTATION HINTS
═══════════════════════════════════════════════════════════════
- `sendChat()` already bypasses all audio pipeline filters and goes
  directly to the LLM. The STAR primer will be treated as a high-priority
  user instruction by the LLM.
- The 3-second visual "primed" state reassures the user the primer was
  sent, without cluttering the UI permanently.
- `animate-pulse` gives a subtle breathing glow, matching the existing
  mock-mode button style.
- The button is text-only ("STAR") not icon-only — this makes it
  immediately understood by a stressed interview candidate.
- The yellow color palette (`text-yellow-300`, `bg-yellow-400`) is
  deliberately different from primary (blue/green) to signal "formatting
  mode", not "send" mode.
