2. EDGE FUNCTION: supabase/functions/paddle-webhook/index.ts
──────────────────────────────────────────────────────────────
A Deno Edge Function that receives POST requests from Paddle webhook system.

SECURITY: Verify the Paddle-Signature header using HMAC-SHA256.
  - Read secret from env var: PADDLE_WEBHOOK_SECRET
  - Paddle sends header: Paddle-Signature: ts=<timestamp>;h1=<hmac_hex>
  - Construct the signed payload as: <timestamp>:<raw_body>
  - Compare h1 against HMAC-SHA256(PADDLE_WEBHOOK_SECRET, signed_payload)
  - Return 401 if signature does not match.

Handle the following Paddle event types (read from event_type in JSON body):

  A) transaction.completed
     Fired when a one-time payment (lifetime deal) completes.
     Extract from event data:
       * customer.id -> paddle_customer_id
       * customer.email -> use to look up Supabase user by email
       * items[0].price.product_id -> map to product_mode using env vars:
           PADDLE_PRODUCT_INTERVIEW -> 'interview'
           PADDLE_PRODUCT_MENTOR    -> 'mentor'
           PADDLE_PRODUCT_COUNSEL   -> 'counsel'
           PADDLE_PRODUCT_CLINIC    -> 'clinic'
       * Generate a license_key: crypto.randomUUID()
     Upsert into user_entitlements:
       * product_mode = mapped value
       * remaining_sessions = 999999 (lifetime = unlimited)
       * license_key = generated UUID
       * paddle_customer_id = from event

  B) subscription.activated and subscription.updated
     Fired when a SaaS subscription starts or changes.
     Extract: subscription_id, customer_id, customer_email,
       current_billing_period.starts_at, current_billing_period.ends_at,
       items[0].price.product_id
     Map product_id to product_mode using same env var pattern above.
     Set included_seconds based on product_mode:
       * 'mentor'  -> 3600 * 20  (20 hours/month)
       * 'counsel' -> 3600 * 40  (40 hours/month)
       * 'clinic'  -> 3600 * 30  (30 hours/month)
     Upsert into user_entitlements:
       * paddle_subscription_id, paddle_customer_id
       * billing_period_start, billing_period_end
       * included_seconds
       * usage_seconds = 0 (reset on new period)

  C) subscription.canceled
     Set remaining_sessions = 0 and demo_expires_at = now() to gate the user.

For all events: respond HTTP 200 with {"received": true}.

──────────────────────────────────────────────────────────────
3. EDGE FUNCTION: supabase/functions/paddle-billing-cron/index.ts
──────────────────────────────────────────────────────────────
A Deno Edge Function acting as a monthly billing cron job.
Called by Supabase CRON schedule or manually via HTTP POST with bearer token.

SECURITY: Verify bearer token matches env var CRON_SECRET.

LOGIC:
  1. Query all rows from user_entitlements where:
       paddle_subscription_id IS NOT NULL
       billing_period_end <= now() + interval '1 day'
       usage_seconds > included_seconds

  2. For each row with overage:
       overage_seconds = usage_seconds - included_seconds
       overage_minutes = Math.ceil(overage_seconds / 60)
       rate_per_minute from env var by product_mode:
         PADDLE_RATE_MENTOR_PER_MIN  (default "0.02")
         PADDLE_RATE_COUNSEL_PER_MIN (default "0.03")
         PADDLE_RATE_CLINIC_PER_MIN  (default "0.025")
       overage_amount_usd = overage_minutes * rate_per_minute
       If overage_amount_usd < 0.50, skip (below Paddle minimum charge)

  3. For each chargeable row, call Paddle API:
       POST https://api.paddle.com/transactions
       Authorization: Bearer {PADDLE_API_KEY}
       Body (JSON):
         {
           "items": [{
             "price": {
               "description": "Usage overage - {overage_minutes} mins",
               "unit_price": { "amount": "<cents_string>", "currency_code": "USD" },
               "quantity": { "minimum": 1, "maximum": 1 }
             },
             "quantity": 1
           }],
           "customer_id": "<paddle_customer_id>",
           "collection_mode": "automatic"
         }

  4. After charging, reset usage_seconds = 0 and advance billing_period_start/end
     by one month in user_entitlements.

  5. Return a summary JSON: { charged: N, skipped: N, errors: N }

ENV VARS required (document in a comment block at the top of each file):
  SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY,
  PADDLE_API_KEY, PADDLE_WEBHOOK_SECRET, CRON_SECRET,
  PADDLE_PRODUCT_INTERVIEW, PADDLE_PRODUCT_MENTOR,
  PADDLE_PRODUCT_COUNSEL, PADDLE_PRODUCT_CLINIC,
  PADDLE_RATE_MENTOR_PER_MIN, PADDLE_RATE_COUNSEL_PER_MIN, PADDLE_RATE_CLINIC_PER_MIN
