TASK: P64-T3 — Paddle Billing Webhook Setup

═══════════════════════════════════════════════════════════════
OBJECTIVE
═══════════════════════════════════════════════════════════════
We need a Supabase Edge Function to handle incoming webhooks from Paddle (transaction and subscription events) and update the user's entitlements in the `user_entitlements` table.

═══════════════════════════════════════════════════════════════
FILES TO MODIFY
═══════════════════════════════════════════════════════════════
CREATE: supabase/functions/paddle-webhook/index.ts
CREATE: supabase/functions/paddle-webhook/deno.json

═══════════════════════════════════════════════════════════════
DETAILED SPECIFICATION
═══════════════════════════════════════════════════════════════

1. **Edge Function Setup (`paddle-webhook`)**
   - Create a standard Deno Edge function using `Deno.serve`.
   - Read the incoming request body as text (needed for signature verification).
   - Get the `paddle-signature` header.

2. **Signature Verification**
   - Use the `PADDLE_WEBHOOK_SECRET` environment variable to verify the HMAC-SHA256 signature according to Paddle's v1 webhook specification:
     - Parse the signature header (e.g. `ts=123;h1=abc...`).
     - Recreate the signed payload: `${ts}:${body}`.
     - Calculate the HMAC-SHA256 hash using the secret and compare it to `h1`.
   - If the signature is invalid, return a 401 Unauthorized response.

3. **Event Processing**
   - Parse the JSON body.
   - Handle the following events:
     - `transaction.completed`
     - `subscription.activated`
     - `subscription.updated`
     - `subscription.canceled`
     - `subscription.past_due`
   - Extract the `customer_id` and the `custom_data.user_id` from the payload (or extract from the transaction checkout data).

4. **Database Update (`user_entitlements`)**
   - Initialize the Supabase admin client using `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY`.
   - Update the `user_entitlements` table for the corresponding `user_id`.
   - Set `paddle_subscription_id` to the incoming subscription ID (if active/updated). Set to null or inactive if canceled/past_due.
   - Set `plan_type` to the product ID or name.

═══════════════════════════════════════════════════════════════
VERIFICATION
═══════════════════════════════════════════════════════════════
- Ensure Deno standard libraries are imported correctly in `deno.json`.
- The HMAC logic must properly parse the timestamp and hash it exactly as Paddle specifies.
- The Supabase client must use the service role key to bypass RLS when updating entitlements from the webhook.
