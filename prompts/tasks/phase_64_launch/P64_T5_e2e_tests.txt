DETAILED SPECIFICATION
═══════════════════════════════════════════════════════════════

1. **Refactor `App.svelte` for Reactive Product Mode:**
   - Currently, `App.svelte` might be hardcoding product mode. Ensure it reacts to `authState.productMode` properly so the UI toggles when Playwright mutates it.
   
2. **Scrap and Rewrite `entitlement.spec.ts`:**
   - Delete all the `.innerHTML += ...` fake DOM injection from the existing file.
   - Use `page.evaluate()` to mutate `(window as any).__authState`. Since Svelte 5 `$state` objects are deep proxies, mutating it directly via the window object will trigger Svelte to re-render the actual components!

3. **What to Mock and How to Test:**
   - **Test 1: BarnOwl AI (Interview Mode) — Developer Mode Bypass**
     - **Mock:** `window.__authState.authMode = 'saas'; window.__authState.productMode = 'interview'; window.__authState.licenseStatus = 'dev_allowed';`
     - **Action:** Open the Settings modal by clicking the gear icon in the UI.
     - **Assert:** The real Svelte `<Settings>` component renders a "Developer Mode" or "Unlocked" badge.
     
   - **Test 2: BarnOwl AI (Interview Mode) — Active License**
     - **Mock:** `window.__authState.licenseStatus = 'active'; window.__authState.productMode = 'interview';`
     - **Action:** Open the Settings modal.
     - **Assert:** The text "Lifetime License — Active" is visible in the settings panel.
     
   - **Test 3: SaaS Products — Standard Usage Meter**
     - **Mock:** `window.__authState.productMode = 'saas'; window.__authState.user = { email: 'test@example.com' }; window.__authState.userEntitlements = { usage_seconds: 18000, included_seconds: 36000 };`
     - **Action:** Open the Settings modal.
     - **Assert:** The `<Settings>` component renders the real text "5h 0m used / 10h 0m included" (or however it is formatted natively in the component).
     
   - **Test 4: SaaS Products — Paddle Overage Warning**
     - **Mock:** Same as above, but `usage_seconds: 40000`.
     - **Assert:** Ensure the "Overage" warning text natively appears in the UI.
     
   - **Test 5: SaaS Products — Subscription Status**
     - **Mock:** `window.__authState.paddleStatus = 'active'` vs `window.__authState.paddleStatus = 'inactive'`.
     - **Assert:** Check that the real Svelte UI shows the "Active Subscription" badge or "Inactive" text based on the mock.
